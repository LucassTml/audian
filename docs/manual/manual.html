1What Audian is

Audian is a small background utility. You press a keyboard shortcut in any app, speak the way you talk, and Audian inserts a clean, well-formed version of what you meant — not a literal transcript — at your text cursor.

Saying "um so basically I, I want to make this thing work better and like organize the code because it's kinda messy" produces "I want to make this work better and organize the code, because it's kind of messy." in Natural mode, or "Improve the implementation and organize the code to make it cleaner and more maintainable." in AI Prompt mode.

The pipeline

Design principles

  • Private by default. Speech recognition and rewriting run on your CPU. Nothing is sent anywhere unless you choose the Antigravity cloud provider.
  • Invisible until needed. The tray app idles at ~11 MB of RAM and 0 % CPU. The AI engines are separate processes that start when you press the shortcut and exit as soon as your text is inserted.
  • Works everywhere you type. Text is pasted through the clipboard, which every Windows app understands — editors, browsers, chat apps, Office, terminals — and your clipboard is restored afterwards.
  • Yours to style. Six colour themes — Ivory (off-white, the default), Violet, Ocean, Mint, Sunset and Rose — for the window, the logo and the recording indicator, which can also be dark or light.
  • Fails gracefully. If the AI fails, a basic cleanup is inserted; if the window closed or is elevated, the text goes to your clipboard and a notification explains why.

2Installing & first run

Run Audian-Setup-1.0.0-x64.exe. It installs for your Windows account only, so no administrator rights are needed (the same model as VS Code's user installer). Requirements: Windows 10 or 11, 64-bit x86 CPU with AVX2 (any Intel/AMD CPU from roughly 2015 on), 8 GB RAM recommended (4 GB works with the lighter models).

First run

On first launch Audian opens a short welcome: (1) download the models if they're missing, (2) pick and test your microphone, (3) learn the shortcut. After that it lives in the system tray.

3Dictating

Click into any text field, then use your shortcut (default Ctrl+Shift+Space; yours is set to Ctrl+Shift+V).

StyleHow it worksBest for
Hybrid (default)Hold the shortcut while speaking and release to finish — or tap it once and just talk; Audian finishes when you pause (or when you tap again).Everything
Push-to-talkRecords only while the shortcut is held.Short phrases, noisy rooms
TogglePress to start; press again or pause to finish.Long, hands-free dictation

Esc cancels a dictation at any point. Ctrl+Shift+Alt+V pastes your last dictation again (configurable).

The recording indicator

A small pill appears near your text cursor (or at the bottom of the screen if the app doesn't expose its cursor). It never takes focus and clicks pass through it.

While processing, the pill shows Transcribing… then Polishing…. Soft chimes mark start and stop (can be turned off under Microphone & sound). Its colours, dark or light style, position and label are set under Appearance.

Where the text goes

  • Audian remembers the window you were in when you pressed the shortcut, and pastes there — even if you clicked elsewhere while it was processing (it switches back first).
  • Your clipboard is saved before pasting and restored ~0.6 s later. Dictated text is excluded from Win+V clipboard history and cloud clipboard.
  • In terminals, multi-line results are joined into one line so nothing runs by accident. mintty/PuTTY receive Shift+Insert.
  • If the window was closed, or runs as administrator (Windows blocks input from normal apps into elevated ones), the text is placed on the clipboard and a notification tells you to press Ctrl+V.

4Knowing when you're done

In hands-free dictation Audian decides when you've finished speaking — quickly when you've completed a sentence, patiently when you pause mid-thought.

How it decides

  1. Voice activity detection runs on every 10 ms of audio and tracks your room's background noise, so it knows the difference between “quiet” and “speaking” on any microphone.
  2. When you pause (≈0.5 s), Audian quietly transcribes what you've said so far (a “preview”).
  3. If the preview sounds finished (“…send it to Maria.”), Audian stops after your pause tolerance (default 2.0 s).
  4. If it sounds unfinished — it ends with “and”, “but”, “because”, “the”, a comma, “um”, or Portuguese “e”, “mas”, “porque”, “que”, “de”… — Audian waits the extra patience as well (default +1.5 s).
  5. When it stops, the preview is reused, so your text usually appears 0.3–1 s later.
Tuning itShortcut & recording › Finish automatically. Presets: Quick 1.2 s, Balanced 2 s, Patient 3 s, or any value 0.6–6 s. You can also disable smart detection (pure silence timer) or auto-stop entirely (then tap the shortcut to finish). If nothing is said for 8 s, the dictation is cancelled.

Output language (translate as you dictate)

Under Rewriting › Output language (or the tray menu) choose a language to always write in. Speak Portuguese, get English — or the reverse. Tested results: “Você pode me explicar como funciona o borrow checker do Rust?” → “Can you explain how the Rust borrow checker works?”; “Can you check if the build is passing before we merge?” → “Pode verificar se o build está passando antes de fazer o merge?”. English and Portuguese have built-in examples for the local model; other target languages work best with the Antigravity provider.

Recognizing two languages

With Spoken language: Auto-detect, tick the languages you actually speak (e.g. English + Portuguese). Detection then only chooses among those — avoiding mix-ups such as short Portuguese phrases being detected as Galician or Spanish — and is faster.

Task Manager's default Memory column counts only private memory, so it shows less than Audian's own resource card, which shows each engine's full working set. Version 0.2.0 peaked at 1.96 GB for the rewriting engine: llama.cpp kept a second, “repacked” copy of most weights (0.5 GB) and reserved a 0.5 GB compute buffer for 512-token batches. Audian now uses the mapped weights directly and 128-token batches, with no measurable change in rewriting speed.

Only working when necessary

  • The microphone is opened only while recording (the Windows mic indicator is off otherwise).
  • The engines are separate processes started by the shortcut, not at boot, and they exit as soon as the dictation is done — also when it is cancelled or contained no speech — or after the idle time you chose. A Windows Job Object guarantees they never outlive Audian.
  • The tray app uses no timers while idle: key-release polling runs only while you hold the shortcut, voice detection only during hands-free dictation, and the overlay animation only while it is visible.
  • Preview transcriptions happen only during pauses in hands-free mode.
  • OpenMP is disabled in the rewriting engine, so its threads don't spin-wait after each request.
  • The settings window is a separate process, so its GUI memory exists only while it is open.
  • After each dictation the tray app returns its temporary memory to Windows.

9Models: what we chose and why

Speech recognition — Whisper Small (Q8) by default

Whisper (OpenAI, MIT licence) running through whisper.cpp is the most mature offline speech engine on Windows, handles 99 languages including Portuguese, and needs no GPU. On a CPU the decisive factor is speed:

Whisper Small Q8264 MB456 MB0.4–1.4 s~7.7 %default — best speed/accuracy on CPU
Whisper Small English264 MB456 MB≈0.4 s—you only speak English

Whisper Large v3 Turbo Q5574 MB777 MB3–8 s~4.2 %accents, noisy audio; or with a GPU build

Why Small: it is 4–6× faster than Large v3 Turbo on this CPU while being good enough for clean dictation — and the rewriting step fixes most remaining recognition slips (“end” → “and”). Turbo is the better choice once speed is not limiting (e.g. a GPU build). Worth adding next: NVIDIA Parakeet TDT 0.6B v3 (ONNX) is roughly 2× faster than Small on CPU with Turbo-like accuracy (~5 % Portuguese error rate) for 25 European languages — it would plug in behind the same TranscriptionProvider interface but requires the ONNX Runtime.

* Typical sentence on this CPU. RAM is the engine's working set while rewriting, including the memory-mapped model file; figures with “~” are estimates from file size and context shape.

Why Qwen 3.5 2B: rewriting needs a model that follows rules precisely (keep the meaning, don't answer questions, keep the language) while being fast enough to feel instant. In our tests the 2B model resolved self-corrections, removed fillers, kept Portuguese as Portuguese, never answered questions and translated reliably, at under a second per rewrite on the CPU — with about 1.3 GB of disk. The 0.8B model is noticeably weaker at AI-Prompt restructuring; 4B models are better on long inputs but 2–3× slower and need twice the RAM.

Using your GPU (future option)Both engines can be built with GPU backends (Vulkan or CUDA for the RTX 5060). That would make Whisper Large v3 Turbo take ~0.3 s and allow bigger rewriting models, at the cost of ~1–3 GB of VRAM while loaded. Audian ships CPU-only so it works on every PC with no drivers involved.

Any whisper.cpp ggml-*.bin model or instruction-tuned GGUF chat model placed in the models folder appears in the app as a “custom” model.

10How it works inside

Process model

ProcessRoleTechnology

agy.exe (optional)Cloud rewriting through AntigravityAntigravity CLI with a tool-less custom agent

Engines talk to the tray app over their stdin/stdout pipes with a framed protocol (length-prefixed JSON control messages, binary frames for 16 kHz PCM audio). Separate processes keep the tray app tiny, return model memory to Windows on exit, isolate crashes in native code, and let whisper.cpp and llama.cpp each use their own ggml library (they cannot be linked into one binary).

A dictation, step by step

  1. Shortcut (RegisterHotKey; conflicts are reported). Audian notes the focused window, its caret position, process and title (title is used only for per-app modes, never logged).
  2. Recording starts within ~20 ms (WASAPI shared mode, device's native rate). In parallel, the engines start and load their models; the rewriting engine restores its prompt prefix from the cache.
  3. Voice detection on 10 ms blocks; the overlay animates from the same levels.
  4. End: key release (push-to-talk), second tap, or auto-stop.
  5. Audio preparation: windowed-sinc resampling to 16 kHz, trimming of leading/trailing silence, normalisation.
  6. Transcription (unless the pause preview can be reused).
  7. Rewriting with the session's mode; output sanitised (strip echoed tags/labels/quotes, reject outputs far longer than the input — the sign of an answer instead of a rewrite).
  8. Insertion: verify/restore focus → wait for modifier keys to be released → clipboard snapshot → paste → restore clipboard after 0.6 s unless you copied something new meanwhile.
  9. History & stats recorded (text only); engines exit (with “After use”); memory trimmed.

Voice activity detection

Each 10 ms block's loudness (dBFS) is compared with an adaptive noise floor. The floor follows the quietest recent level — falling quickly, rising only 3 dB/s — so steady noise like fans is learned within seconds while the natural dips between words keep it from creeping up during speech. A block is voiced when it is margin dB above the floor (16 dB at sensitivity 0, 6 dB at sensitivity 1; default 11 dB; never below −60 dBFS). Speech starts after 3 voiced blocks (30 ms: ignores clicks) and ends after 200 ms of unvoiced blocks (bridges gaps between words). The detector also rejects recordings with no speech before any AI runs.

Local rewriting

  • Prompt: strict rules (edit, never answer; keep language, meaning, names; remove fillers; resolve self-corrections) + a mode style + your custom instructions + 6 few-shot examples written like real Whisper output, in English and Portuguese.
  • Prefix caching: the system prompt and examples (~640 tokens) are evaluated once and the model state is snapshotted (~27 MB), in memory and on disk (%LOCALAPPDATA%\Audian\cache, the 6 most recent prompts). A freshly started engine restores it in ~25 ms instead of re-evaluating it (~3.5 s), and each dictation only processes its own ~40–60 tokens. Qwen 3.5 is a hybrid recurrent model, so a state snapshot is used rather than truncating a KV cache.
  • Lean memory: weights are used straight from the memory-mapped file (llama.cpp's repacked weight copy is disabled) and the micro-batch is 128 tokens, which keeps the compute buffer — sized by the vocabulary's logits — at ~0.13 GB instead of ~0.5 GB.
  • Decoding: greedy (deterministic), “thinking” disabled, output length capped relative to the input.
  • Translation uses example answers in the target language, which a 2B model follows far more reliably than an instruction alone.

Antigravity integration

Audian keeps a private workspace (%LOCALAPPDATA%\Audian\agy-workspace) containing a custom agent with no tools and a minimal prompt — about 700 input tokens per request instead of ~12 000 for the default coding agent. The CLI is started in streaming mode when you press the shortcut, so its start-up overlaps your speech.

Text insertion details

  • Clipboard snapshot copies every memory-based format (text, rich text, HTML, images as DIB, file lists), up to 64 MB.
  • Dictated text is tagged ExcludeClipboardContentFromMonitorProcessing, CanIncludeInClipboardHistory=0, CanUploadToCloudClipboard=0.
  • For Alt/Win shortcuts, an unassigned key is injected so releasing the modifier doesn't open menus or Start.
  • Elevation is detected by comparing token integrity levels; elevated targets receive the text via clipboard + notification.
  • “Simulate typing” sends Unicode key events (newlines as Shift+Enter so chat apps don't send early); used as fallback when the clipboard is locked.

14Building & publishing

Requirements: Rust (MSVC toolchain), Visual Studio 2022 Build Tools with C++ build tools, Windows 11 SDK and C++ Clang Compiler for Windows, plus CMake.

.\scripts\package.ps1      # + installer      → dist\Audian-Setup-1.0.0-x64.exe (prints size and SHA-256)
cargo test --release       # unit tests (config, IPC, VAD, auto-stop, hotkeys, DSP, rules, sanitizer)
CrateRole
audianTray app + Audian window
audian-stt / audian-llmSpeech and rewriting engines
audian-setupInstaller/uninstaller; embeds the app binaries (deflate-compressed)
audian-commonConfig, model catalog, downloader, history, IPC, logging, WAV
audian-ui / audian-art / audian-buildDesign system · vector artwork · icon/manifest/version embedding
Before publishingThe installer is not code-signed, so Windows SmartScreen will warn users downloading it (“Windows protected your PC”). Signing it with a code-signing certificate (or distributing through the Microsoft Store / winget) removes the warning. Models are downloaded from Hugging Face on the user's machine — check the model licences (Whisper: MIT; Qwen 3.5: Apache-2.0; Llama 3.2: Llama Community License) if you redistribute them.
